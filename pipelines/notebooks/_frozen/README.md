## Frozen Notebooks

Esta pasta concentra notebooks retirados dos jobs principais.

Criterios usados:
- orquestradores `run_all` de uma abordagem antiga
- notebooks Silver legados que misturam limpeza com relacionamento
- notebooks Gold de extensao ou de uma modelagem antiga baseada em `stg_*`

Esses notebooks seguem versionados para consulta e refatoracao futura, mas nao fazem parte do core atual do pipeline.
